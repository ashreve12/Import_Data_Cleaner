Merge into Master Workbook

Upload the cleaned output file from the cleaner above, then upload the master destination workbook you want to merge it into. Columns are matched by exact header name and new rows are appended below the existing data.

Source file: the cleaned workbook produced by the cleaner (e.g. Cell_Import_Final.xlsx). The sheet named DATA_AICleaned or DATA_Final is used automatically.
Destination file: your master workbook. Data is appended below the last row — existing data is never overwritten.
Column matching: exact header strings only. Columns in the destination with no match in the source are left blank or carry formulas forward.

Select up to 3 cleaned output files (e.g. Cell_Import_Final.xlsx, Module_Import_Final.xlsx, Wafer_Import_Final.xlsx). Each is merged into the destination in order.
